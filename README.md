# Tropa

Локальная «дорожная карта» проекта: большая цель раскладывается на этапы, задачи и подзадачи, а агент правит карту прямо во время работы. Полное описание — в [prd.md](prd.md).

Сделаны все этапы плана: **0 (разведка)**, **1 (ядро)**, **2 (MCP)**, **3 (интерфейс списком)**, **4 (канвас)** и **5 (доводка)**. Карту видно двумя способами — списком и нодами на полотне, переключатель в шапке.

## Запуск

Первый раз — поставить зависимости сервера и интерфейса и собрать интерфейс:

```bash
npm install
```
```bash
npm.cmd run web:install
```
```bash
npm.cmd run web:build
```

Дальше достаточно одной команды:

```bash
npm.cmd start
```

Приложение открывается на `http://127.0.0.1:4317` — там и интерфейс, и API (`/api`). Слушает только локальный адрес, авторизации нет.

Если правите сам интерфейс, удобнее запустить его отдельно, с мгновенной перезагрузкой: `npm.cmd start` в одном окне и `npm.cmd run web:dev` в другом, страница тогда на `http://127.0.0.1:5173`.

Проверка, что всё живо:

```bash
npm.cmd run smoke
```

Это сквозной тест: поднимает API на временной папке, создаёт карту с этапами и задачами, читает обратно и проверяет защиты. 26 проверок.

> На этой машине в PowerShell запрещены скрипты, поэтому `npm` пишется как `npm.cmd`. В обычном терминале достаточно `npm start`.

## Где лежат карты

`%USERPROFILE%\.tropa\` (на Windows это папка `.tropa` внутри домашней папки пользователя)

| Папка | Что внутри |
|---|---|
| `roadmaps/` | по одному JSON-файлу на карту |
| `history/<id>/` | автокопии: файл копируется перед каждой записью, хранятся последние 50 |

Папку можно переназначить переменной `TROPA_HOME` — этим пользуется тест, чтобы не трогать настоящие карты.

## API

Всё под `/api`.

**Карты**

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/roadmaps` | список карт с прогрессом |
| POST | `/roadmaps` | создать карту |
| GET | `/roadmaps/:id` | карта целиком, компактно |
| PATCH | `/roadmaps/:id` | правка названия, цели, вводных, архив |
| DELETE | `/roadmaps/:id?confirm=true` | удалить |
| GET | `/roadmaps/:id/history` | список автокопий |
| GET | `/roadmaps/:id/export` | карта целиком в markdown |
| GET | `/templates` | встроенные шаблоны карт |
| POST | `/roadmaps/from-template` | создать карту по шаблону |

**Этапы и задачи**

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/roadmaps/:id/stages` | создать этап |
| PATCH / DELETE | `/roadmaps/:id/stages/:stageId` | правка и удаление |
| POST | `/roadmaps/:id/tasks` | создать задачу |
| POST | `/roadmaps/:id/bulk` | дерево за один вызов, до 40 задач |
| GET | `/roadmaps/:id/next-task` | первая задача со свободными зависимостями |
| GET | `/roadmaps/:id/search?q=&status=&file=` | поиск |
| GET | `/roadmaps/:id/tasks/:taskId` | задача со всеми полями |
| PATCH | `/roadmaps/:id/tasks/:taskId` | правка полей |
| POST | `/roadmaps/:id/tasks/:taskId/status` | сменить статус |
| POST | `/roadmaps/:id/tasks/:taskId/position` | координаты одной ноды |
| POST | `/roadmaps/:id/positions` | вся раскладка канваса одной записью |
| GET | `/roadmaps/:id/tasks/:taskId/prompt` | готовый текст задачи для Claude |
| POST | `/roadmaps/:id/tasks/:taskId/notes` | дописать заметку |
| DELETE | `/roadmaps/:id/tasks/:taskId/notes/:noteId?confirm=true` | убрать заметку |
| POST / DELETE | `/roadmaps/:id/tasks/:taskId/links` | связи между задачами |
| POST / PATCH / DELETE | `.../subtasks` | чеклист внутри задачи |

**Что API не даёт сделать**

- создать задачу без заголовка или в несуществующем этапе
- поставить статус `blocked` без причины
- сохранить правку со старым номером версии — вернётся 409 и текущий номер
- замкнуть круг зависимостей
- удалить что-либо без `confirm=true`
- создать больше 40 задач за один вызов `bulk`
- задать координаты через обычную правку задачи: для этого отдельная ручка, чтобы агент не разъезжал раскладку

## MCP: что получает агент

Сервер прописан в `.mcp.json` этой папки под именем `tropa`. Чтобы инструменты стали доступны, сессию агента нужно открыть **с рабочей папкой `tropa`** — список MCP читается при её старте.

> В `.mcp.json` записан полный путь до `mcp/server.js` на машине автора. Если вы склонировали репозиторий себе — поправьте его на свой, иначе агент сервер не найдёт.

```bash
npm.cmd run mcp:check
```

Полная сквозная проверка: поднимает MCP-сервер настоящим процессом по stdio и проходит все инструменты, как это делал бы агент. 75 проверок, карты пишутся во временную папку.

```bash
npm.cmd run mcp:check:external
```

Проверка второго режима: когда `npm start` уже запущен, MCP ходит в него, а не поднимает свой API. Так агент и браузер работают с одной картой.

**Чтение**

| Инструмент | Что делает |
|---|---|
| `list_roadmaps` | все карты с прогрессом |
| `get_roadmap` | карта компактно: этапы, заголовки, статусы, связи |
| `get_task` | задача со всеми полями, подзадачами и заметками |
| `get_next_task` | главный: первая задача со свободными зависимостями |
| `search_tasks` | поиск по тексту, статусу или файлу |

**Запись**

| Инструмент | Что делает |
|---|---|
| `create_roadmap` | новая карта с целью и вводными |
| `bulk_create` | дерево за один вызов, до 40 задач |
| `create_stage` / `create_task` / `create_subtask` | точечное добавление |
| `update_task` | правка полей задачи |
| `set_status` | смена статуса; для `blocked` обязательна причина |
| `toggle_subtask` | галочка в чеклисте |
| `add_note` | дописать, что сделано или на чём застряли |
| `delete_note` | убрать запись из ленты, только с `confirm=true` |
| `link_tasks` / `unlink_tasks` | связи между задачами |
| `delete_roadmap` / `delete_stage` / `delete_task` / `delete_subtask` | удаление, только с `confirm=true` |

Плюс `ping` для диагностики: отвечает «pong» и показывает, к какому API подключён.

**Два правила раздела 7 заложены в код, а не в уговор**

1. Координат `x`/`y` нет ни во входных данных инструментов, ни в их ответах — раскладку агент не трогает физически.
2. `get_roadmap` и `search_tasks` отдают только заголовки, статусы и связи. Описаний, критериев приёмки и заметок там нет: за ними агент идёт в `get_task`. Вводные карты (`context`) тоже не разворачиваются — вместо текста приходит его длина.

### Этап 0: мини-MCP

В `mcp-probe/` остался минимальный сервер этапа 0 с одним инструментом `ping` (`node mcp-probe/check.js`). В `.mcp.json` он больше не прописан: его `ping` теперь есть в основном сервере.

## Интерфейс

Один экран, три зоны, тёмная тема (PRD, раздел 8).

**Сайдбар слева (260px).** Поиск по картам и этапам. Список карт с колечком прогресса и счётчиком. Этапы активной карты, фильтр «Все / Активные / Готовые», клик по этапу подкручивает дерево к нему. Внизу — лампочка живого обновления.

**Центр.** Дерево «этап → задача → подзадачи». Цвет точки = статус, красная метка «блокируется N» = незакрытые зависимости, счётчик вида 0/4 раскрывает чеклист. Подзадачи подтягиваются только для раскрытых задач, чтобы не тащить лишнее.

**Панель справа.** Статусы кнопками (для «заблокирована» спрашивается причина), описание, чеклист, критерии приёмки, файлы, блок «блокируется / блокирует» с переходом по клику, лента заметок. Всё правится по клику: Enter сохраняет, Esc отменяет.

### Канвас

Переключатель «Список / Канвас» в шапке; выбранный вид запоминается.

Нода — задача: заголовок, полоска прогресса подзадач, цвет точки и полоски по статусу, рамка по цвету этапа. Чем ближе зум, тем больше видно: издалека только цветной прямоугольник с названием, посередине — заголовок со счётчиком, вблизи — ещё и первые строки описания. Описания подтягиваются только на близком зуме, чтобы не тащить лишнее.

Стрелки — зависимости. Тянутся мышкой от правого края одной ноды к левому краю другой; замкнуть круг сервер не даст. Выделить стрелку и нажать Delete — связь снимается.

Кнопка «Разложить автоматически» раскладывает ноды Dagre: слева направо по зависимостям, задачи одного этапа держатся рядом. Если у карты ещё нет раскладки (агент координаты не ставит), канвас раскладывает её сам при первом открытии. Координаты сохраняются отдельными ручками API, обычная правка задачи их не трогает.

Миникарта в правом нижнем углу, кнопки зума — в левом. Клик по этапу в сайдбаре подлетает к его группе нод.

**Живое обновление.** Браузер держит открытым `GET /api/events`. Любая запись — хоть из браузера, хоть от агента — проходит через одно место в коде и шлёт событие, так что забыть уведомить вкладку невозможно. Строка, которую изменил агент, подсвечивается на две секунды; свои правки не подсвечиваются.

Чтобы правки агента долетали до вкладки, MCP должен ходить в тот же сервер — то есть `npm.cmd start` должен быть запущен. Если сервера нет, MCP поднимет свой внутри себя, и браузеру о его правках узнать неоткуда.

## Доводка (этап 5)

**Шаблоны карт.** Кнопка «+» над списком карт открывает выбор: пустая карта, учебный курс,
небольшой проект, большой текст. У трёх последних уже есть этапы, задачи, чеклисты и критерии
приёмки, а задачи связаны по очереди — следующая ждёт предыдущую. Название можно задать сразу.

**Экспорт в markdown.** Кнопка «Выгрузить .md» в шапке (или клавиша M) сохраняет карту файлом:
цель, прогресс, этапы, задачи со статусами, чеклистами, критериями, файлами и заметками.

**Промпт для задачи.** Внизу панели задачи — «Скопировать промпт для Claude»: карта, этап, цель,
описание, шаги, критерии приёмки, чем заблокирована, и просьба отметиться в Tropa, когда сделано.
Если браузер не даёт писать в буфер обмена, текст показывается окном — выделен, остаётся нажать Ctrl+C.

**Markdown в описании.** Заголовки, списки, цитаты, код, жирный, курсив и ссылки. Разметчик свой,
на полсотни строк: сторонняя библиотека ради этого в стек не добавлялась, а текст превращается
в обычные элементы страницы, поэтому вставить через описание чужой скрипт нельзя.

**Горячие клавиши** (подсказка — кнопка «?» в шапке или сама клавиша «?»):

| Клавиши | Что делают |
|---|---|
| ↑ ↓ или J K | перейти к соседней задаче |
| 1 2 3 4 | статус: не начата, в работе, заблокирована, готова |
| P | скопировать промпт для Claude |
| N | новая задача в этом этапе |
| C | переключить список и канвас |
| M | выгрузить карту в markdown |
| / | поиск в сайдбаре |
| Esc | закрыть панель или окно |

Пока курсор в поле ввода, клавиши не срабатывают. Буквы работают и в русской раскладке.
